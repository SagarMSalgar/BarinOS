ZAYA Web Application Support — Demo

This page demonstrates the embeddable ZAYA widget for web applications (Zendesk, Salesforce, Jira, Notion, HR, etc.). Use the floating "Z" button or the buttons below to open the panel with different app contexts.

Config: Set your backend URL below. Default apiBase is http://localhost:8000. Ensure CORS allows this origin and your knowledge base has content for the tenant/namespace.

1. Zendesk / Freshdesk (Support)

Simulate opening a support ticket. ZAYA will show relevant policy, similar tickets, and suggested response.

2. Salesforce / HubSpot (CRM)

Simulate viewing a deal. ZAYA will show account intelligence, open issues, talking points.

3. Jira / Linear (Project)

Simulate viewing an issue. ZAYA will show similar past issues, runbooks, ADRs.

4. Notion / Confluence (Wiki)

Simulate viewing a page. ZAYA will show freshness, conflicts, unanswered questions.

5. HR (Leave / Reimbursement)

Simulate an employee on leave form. ZAYA will show policy, balance, approval process.

6. Custom context

Any custom app can pass context; ZAYA returns relevant docs and key facts.
